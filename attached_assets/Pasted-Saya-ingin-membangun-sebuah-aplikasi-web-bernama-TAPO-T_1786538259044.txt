Saya ingin membangun sebuah aplikasi web bernama TAPO
(Tagging dan Analisis Perubahan Objek Perumahan).

TAPO adalah platform WebGIS untuk mengubah hasil Pendataan Lengkap
Perumahan menjadi informasi spasial, visualisasi, analisis, dan insight
yang mudah dipahami.

UNTUK TAHAP PERTAMA:

Saya hanya ingin membangun prototype untuk satu wilayah terlebih dahulu,
yaitu Kelurahan Boting.

Jangan membuat versi Lagaligo atau Dangerakko terlebih dahulu.

DATA UTAMA:

Saya memiliki dataset hasil Pendataan Lengkap Perumahan Kelurahan Boting
dalam format Excel.

Dataset tersebut akan menjadi sumber data utama aplikasi.

Jangan membuat angka dummy jika data asli dapat digunakan.

TUJUAN PROTOTYPE:

Prototype TAPO Boting harus mampu:

1. membaca dataset perumahan;
2. menampilkan jumlah rumah yang terdata;
3. mengidentifikasi rumah yang mengalami perubahan;
4. menampilkan jenis perubahan;
5. menampilkan lokasi rumah pada peta berdasarkan koordinat;
6. memungkinkan pengguna melakukan filter;
7. menampilkan informasi detail ketika marker rumah diklik;
8. menampilkan tabel data;
9. menampilkan visualisasi perubahan;
10. menghasilkan smart insight sederhana berdasarkan data yang sedang
    ditampilkan.

KONSEP UTAMA:

Data mentah
→ standardisasi data
→ data tabular
→ data spasial
→ visualisasi
→ filter
→ analisis
→ smart insight.

TEKNOLOGI PROTOTYPE:

Frontend:
- React
- TypeScript
- Tailwind CSS

Mapping:
- Leaflet
- React Leaflet

Chart:
- ApexCharts atau library chart yang stabil untuk React

Backend:
- gunakan backend sederhana terlebih dahulu jika belum diperlukan
- jangan membuat arsitektur backend kompleks pada tahap pertama

DATABASE:

Jangan langsung membuat PostgreSQL/PostGIS.

Untuk prototype pertama, gunakan struktur data yang sederhana dan mudah
dikembangkan.

Setelah prototype stabil, baru kita migrasikan ke database spasial.

PRINSIP PENTING:

Saya adalah pengguna yang belum memahami pemrograman secara mendalam.

Karena itu jangan langsung membuat seluruh aplikasi.

Bertindak sebagai Senior Software Architect sekaligus mentor coding.

1. membuat struktur project;
2. membuat halaman utama;
3. membuat layout dashboard;
4. menyiapkan struktur data;
5. menyiapkan komponen peta;
6. menyiapkan komponen grafik;
